## Nota para humanos y para IA

- Humanos: entren por año; verán un resumen y tarjetas tocables.
- IA/agentes: usen los JSON en `datos/leyes/<año>/` y los Markdown/PDF enlazados; cada paquete trae hashes SHA256 y URL oficial.
- Algunos números del inventario se repiten con más de un ID oficial; se preserva una identidad por número y la traza fuente completa en la portada anual.
